# AeroIntel-AI-Flight-Intelligence-System
An interactive Excel Dashboard and Flight Analytics Panel for the AeroIntel AI Flight Intelligence System, featuring dynamic cross-filtering and automated KPI metrics.

## AeroIntel System Core Features
* **AI-Inspired UI Design:** Built on a premium, cohesive dark royal blue canvas with modern curved chart corners.
* **Dynamic Slicers:** Fully interactive cross-filtering capabilities using `AIRLINE` and `FL_DATE` selectors.
* **Precision Percentage KPI Cards:** Custom dynamic cards calculating exact cancellation rates and flight diversion metrics linked seamlessly via report connections.
* **Seamless Navigation:** Integrated an elegant flight vector icon acting as a hyperlink shortcut to browse backend PivotTables instantly.
